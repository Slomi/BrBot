# 💈 Бот онлайн-записи для барбершопа / салона

Telegram-бот, который принимает записи клиентов 24/7 без администратора.

## Возможности

- **Запись в 4 клика:** услуга → мастер → день → свободное время
- **Умное расписание:** показывает только свободные слоты с учётом длительности услуги, рабочих часов и выходных
- **Защита от двойной записи:** два клиента не смогут занять одно время
- **Номер телефона одной кнопкой** (или вручную, с проверкой)
- **Напоминания клиенту** за 2 часа до визита — меньше неявок
- **«Мои записи»:** клиент сам отменяет запись, мастер сразу видит освободившееся время
- **Уведомления администратору** о каждой новой записи и отмене
- **Админка `/admin`:** записи на сегодня / завтра / неделю с ожидаемой выручкой
- Прайс и контакты с картой

## Стек

Python 3.10+, aiogram 3, SQLite (aiosqlite).

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # впишите BOT_TOKEN и ADMIN_IDS
python bot.py
```

Свой Telegram ID можно узнать командой `/myid` в боте.

## Настройка под салон

Всё, что связано с салоном, лежит в `config.py`: название, адрес, часы работы, шаг сетки, выходные, услуги (цена и длительность), мастера. Код для этого трогать не нужно.
