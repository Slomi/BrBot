# Контекст проекта

Демо-бот №1 для портфолио фрилансера (заказы Telegram-ботов на Kwork / FL.ru / Habr Freelance).
Цель: быстро получить первые заказы и отзывы, потом поднимать цены; из повторяющихся запросов вырастить свой продукт.

## Этот бот
Бот онлайн-записи для барбершопа «Бритва» (@Britvaonline_Bot). Python 3.10, aiogram 3, SQLite.
- `bot.py` — запуск, напоминания клиентам
- `handlers/client.py` — запись: услуга → мастер → день → время → телефон → подтверждение; «Мои записи»
- `handlers/admin.py` — `/admin`: записи на сегодня/завтра/неделю с выручкой
- `config.py` — всё, что настраивается под салон; секреты в `.env` (не коммитится)
- `PROXY` в `.env` — если api.telegram.org недоступен у провайдера
